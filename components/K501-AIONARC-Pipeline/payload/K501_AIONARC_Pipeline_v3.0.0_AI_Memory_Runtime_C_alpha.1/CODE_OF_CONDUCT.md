# K501 Information Space — Code of Conduct

**License:** CC BY 4.0 for this document, subject to the package file map.

## Purpose

K501 work prioritizes proof, reconstruction, provenance and careful treatment of uncertainty. Participants are expected to protect both the integrity of technical discussion and the safety of people and their data.

## Expected conduct

- Treat people with dignity; critique claims, code and evidence without harassment or personal attacks.
- Do not discriminate, threaten, intimidate, dox, stalk, or encourage violence against participants or third parties.
- State what is observed, inferred, proposed or unknown. Do not fabricate test results, citations, source provenance, license authority or consensus.
- Respect privacy and data minimization. Do not publish personal, confidential, sensitive or third-party source material without appropriate authority.
- Disclose relevant conflicts, dependencies and uncertainty.
- Report suspected security, privacy, data-integrity or license issues privately to the project maintainer before exposing details that create avoidable harm.
- Preserve historical evidence. Corrections should be appended/versioned rather than concealed by rewriting the record.
- No participant is required to agree with a theory or claim; reasoned disagreement and reproducible counterexamples are welcome.

## Scope and response

This code applies to project spaces and interactions presented as K501 project activity. Reports should include context and evidence where safe to share. The maintainer may request clarification, remove harmful content from project-controlled spaces, pause participation, or apply a proportionate restriction. Actions and reasons should be documented where possible. This code is not a substitute for law, platform rules, incident response procedures or professional advice.
