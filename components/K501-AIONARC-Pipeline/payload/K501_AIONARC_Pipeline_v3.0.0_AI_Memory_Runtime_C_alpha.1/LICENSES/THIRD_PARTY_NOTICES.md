# Third-Party Notices — Alpha 1

No third-party runtime binary is bundled. `pdftotext` is an optional host program; if installed, the terms applicable to that Poppler package are supplied by the host distribution and are not overridden by K501's file map. `libc` and the ELF loader are system runtime components and are not redistributed in this package.

QH256 v2 source is retained as the project core; the current public QH256 repository root presents an MIT license. The new package labels K501-owned/controlled code as MIT according to the rights-holder instruction recorded in `RIGHTSHOLDER_DECLARATION.md`. No exact prior v2.1-C archive is bundled. The SHA-256 source implementation was rewritten for Alpha 1 against the standard SHA-256 algorithm in NIST FIPS 180-4; no external SHA implementation package is bundled.

If a later source or dependency audit identifies additional upstream content, the file map must be amended with exact source, version, license identifier/text, attribution and exclusion boundary before redistribution. Do not infer permission solely from an online page or from public visibility.
