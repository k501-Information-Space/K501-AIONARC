# File License Map — K501-Proof-Evidence-Runtime

`FILE_LICENSE_MAP.csv` is generated from the filesystem observed at apply time. It records paths and classes, including `HOLD/UNRESOLVED`. It is a policy classification, not a representation that every row has independent legal clearance.

Recognized source/build/test code defaults to MIT only where it is original or within the Declarant's licensing authority and no conflicting notice applies. Recognized K501-authored documentation defaults to CC BY 4.0 on the same conditions. A source-specific upstream notice is retained. Unknown/unclassified files remain HOLD.

Review state remains `OPEN` until all file-level origins, notice alignment, package dependencies and third-party rights are reconciled. Do not treat this initial map as the final G5-C decision.
